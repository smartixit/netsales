# Flutter Golden Tests

Golden tests تقارن الصورة المرسومة فعليًا بصورة مرجعية محفوظة. استخدمها للشاشات أو المكونات المستقرة التي تستحق اكتشاف أي تغير بصري فيها.

## مبدأ الاستخدام

1. اجعل بيانات الاختبار ثابتة، ولا تعتمد على الشبكة أو الوقت الحقيقي.
2. ثبّت حجم العرض و`devicePixelRatio` وحجم النص والثيم واللغة والخطوط المستخدمة.
3. شغّل الاختبار في بيئة ثابتة قدر الإمكان؛ اختلاف نظام التشغيل والخطوط ومحرك الرسم قد ينتج فروقات لا تمثل عيبًا حقيقيًا.
4. عند تغيير الواجهة عمدًا، راجع الصورة الجديدة بصريًا قبل تحديث baseline.
5. لا تستخدم `--update-goldens` كإصلاح تلقائي لفشل CI.

يمكن استخدام `matchesGoldenFile('goldens/<screen>.png')` داخل اختبار Widget. انظر ملف المثال `golden_screen_test.dart.example`، وعدّله وأعد تسميته إلى ملف اختبار ينتهي بـ `_test.dart` بعد ربطه بمكوّن حقيقي.
