# مصفوفة اختبار واجهة Flutter

| الفئة | ما ينبغي التحقق منه |
|---|---|
| التشغيل | الشاشة تبدأ دون crash أو استثناء غير معالج |
| التحميل | مؤشر التحميل يظهر ثم يختفي في الوقت المناسب |
| النجاح | البيانات الصحيحة تظهر مع التنسيق الصحيح |
| الفراغ | حالة Empty واضحة مع إجراء مناسب إن وجد |
| الخطأ | رسالة مفهومة، وإمكانية إعادة المحاولة عند إمكانها |
| انقطاع الاتصال | لا يحدث تعليق دائم أو فقد بيانات غير متوقع |
| التحقق | أخطاء الحقول مرتبطة بالمدخلات الصحيحة |
| التكرار | تعطيل الإرسال المتكرر ومعالجة double tap |
| التنقل | back/deep link/الحماية من شاشة غير مصرح بها |
| RTL/LTR | محاذاة واتجاه الأيقونات والنصوص والأرقام صحيحة |
| الاستجابة | لا overflow عند أحجام العرض المدعومة أو تكبير النص |
| الوصول | labels وfocus order وcontrast وtouch targets مناسبة |
| lifecycle | العودة من الخلفية أو تدوير الجهاز لا يفسد الحالة |
