# IBM Plex Sans Arabic

The seven bundled TrueType faces are the official IBM Plex Sans Arabic static
weights sourced from the Google Fonts repository:

- Thin — 100
- ExtraLight — 200
- Light — 300
- Regular — 400
- Medium — 500
- SemiBold — 600
- Bold — 700

Source directory: https://github.com/google/fonts/tree/main/ofl/ibmplexsansarabic

License: SIL Open Font License 1.1. The full license is retained at
`packages/document_engine/assets/licenses/IBM-Plex-Sans-Arabic-OFL.txt`.

The font files are kept as separate real faces. Do not synthesize weights from
Regular or substitute a different family member when a face is available.
